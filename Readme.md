## How to Compile

1. Make sure you have a LaTeX distribution installed:
   - [TeX Live](https://tug.org/texlive/) (Linux/Windows/Mac)
   - [MikTeX](https://miktex.org/) (Windows)
   - [MacTeX](https://tug.org/mactex/) (Mac)

2. Compile `main.tex` using your preferred LaTeX editor:
   - **Command Line**:
     ```bash
     pdflatex main.tex
     ```
   - **Overleaf**:
     Upload all the files and click **Recompile**.

## Features

- 📚 **Modular Structure**: Each CV section is separated into its own `.tex` file.
- 🎨 **Minimalist Design**: Clean and professional layout.
- ⚡ **Easy to Update**: Quickly edit specific sections without touching the full document.
- 🛠️ **Flexible**: Easily add new sections like `projects.tex`, `awards.tex`, etc.
